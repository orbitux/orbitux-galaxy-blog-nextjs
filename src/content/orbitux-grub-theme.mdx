# دانلود و نصب تم گراب orbitux

سلام خدمت تمامی کاربران گرامی . در این پست سعی داریم نحوه نصب صحیح تم گراب orbitux را خدمت شما عزیزان آموزش بدیم.

در این مطلب یاد میگیریم : 

- تم گراب چیست
- نحوه دانلود تم
- اجزای سازنده تم گراب
- نحوه نصب و کانفیگ گراب در توزیع های مختلف لینوکس


## تم گراب چیست؟

در حالت عادی شما وقتی لینوکسی نصب میکنید مثل اوبونتو گراب هم همراهش نصب میشه تا اگر سیستم عامل دیگه ای داشته باشید بتونید به راحتی از منوی گراب وارد سیستم عامل مورد نظر خودتون بشید.
اما این گرابی که نصب میشه به صورت پیشفرض در اکثر توزیع های لینوکسی تم خاصی نداره و یک تم ساده با پس زمینه سیاه داره که شاید زیاد جالب نباشه و خسته کننده باشه.

حال , گراب این امکان رو به ما داده تا بتونیم تم های اختصاصی مطابق با سلیقه خودمون توسعه بدیم که از این رو در استور های مختلف لینوکسی مانند gnome-look , kde store و غیره...
بتونیم تم های مدنظر خودمان را انتخاب و نصب کنیم و شخصی سازی های دلخواه را روش انجام بدیم.

## دانلود فایل تم

ابتدا فایل تم رو از آدرس های دانلود کنید : 

- open desktop : https://www.opendesktop.org/p/2369405
- github : https://github.com/orbitux/orbitux-grub-theme

در صورتی که از گیت هاب دانلود میکنید : 
‍

```bash
git clone https://github.com/orbitux/orbitux-grub-theme.git
```

در صورتی که از opendesktop دانلود میکنید ابتدا باید فایل zip را استخراج کنیم : 

```bash
unzip orbitux-grub-theme-v0.3.0.zip
```

بعد از اینکه با موفقیت دانلود شد وارد دایرکتوری پروژه میشویم 


```bash
cd ~/orbitux-grub-theme
```

و یک بررسی برای اینکه تمامی فایل ها موجود باشند 

```bash
ls
```
این فایل ها باشن وگرنه پروژه به صورت ناقص دانلود شده

## نحوه نصب و کانفیگ گراب در توزیع های مختلف لینوکس

## 1- ساخت دایرکتوری تم

```bash
sudo mkdir -p /boot/grub/themes/orbitux
```

2- وارد دایرکتوری پروژه میشویم

```bash
cd ~/orbitux-grub-theme
```

3- کپی تم در دایرکتوری که در مرحله اول ساختیم 

```bash
sudo cp -r ./* /boot/grub/themes/orbitux/
```

## 4- تنظیمات فایل گراب

فایل تنظیمات گراب را باز میکنیم : 

```bash
sudo nano /etc/default/grub
```

<Callout type="info">

  ما اینجا از ادیتور nano استفاده کردیم. شما میتوانید با هر ادیتوری که راحتید فایل رو باز کنید

</Callout>

در فایل ```/etc/default/grub``` دنبال خط ```GRUB_THEME``` بگردید یا اگر نیست اضافه کنید به این صورت 

آدرس تم رو بهش میدیم 

```
GRUB_THEME="/boot/grub/themes/orbitux/theme.txt"
```
<Callout type="info">

  در برخی توزیع های لینوکس مثل فدورا به جای ```grub``` از ```grub2``` استفاده میکنیم پس حتما این نکترو به خاطر داشته باشید
  
</Callout>


حالا فایل رو سیو میکنیم و برمیگردیم به ترمینال خودمون  و میریم سراغ مرحله بعد 

## 5- Regenerate کردن گراب

این مرحله بسته به توزیع لینوکسی دستورات متفاوتی داره که تقریبا برای اکثر توزیع ها این ۳ دستور استفاده میشه:

```‍grub-mkconfig```

```grub2-mkconfig```

```update-grub```

در ادامه نحوه صحیح generate کردن گراب رو باهم بررسی میکنیم : 

Arch Linux / Manjaro or other

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

Debian/Ubuntu and derivatives

```bash
sudo update-grub
```

Fedora/RedHat bases

```bash
sudo grub2-mkconfig -o /boot/grub2/grub.cfg
```

<Callout type="info">
  لطفا در توزیع لینوکسی خودتان هر ۳ دستور بالارو امتحان کنید ممکن هست برای هر توزیع متفاوت باشه 
</Callout>
