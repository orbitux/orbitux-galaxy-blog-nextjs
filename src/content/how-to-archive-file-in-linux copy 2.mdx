# فشرده‌سازی و آرشیو فایل ها در لینوکس 

تقریباً هر کاربری که مدتی با لینوکس کار کند، دیر یا زود با فایل‌هایی مانند .tar.gz، .tar.xz یا .zip روبه‌رو می‌شود. اگر تا به حال از خودتان پرسیده‌اید که تفاوت این فرمت‌ها چیست یا چرا بعضی فایل‌ها پسوند .tar.gz دارند، این مقاله برای شماست.


در این مطلب یاد می‌گیریم:

- تفاوت آرشیو و فشرده سازی
- نحوه ساخت فایل های آرشیوی
- فشرده کردن فایل‌ها با الگوریتم‌های مختلف
- استخراج فایل‌ها
- مقایسه سرعت و میزان فشرده‌سازی هر روش


### تفاوت آرشیو (Archive) و فشرده‌سازی (Compression) 

یکی از رایج‌ترین اشتباهات کاربران این است که فکر می‌کنند دستور `tar` فایل‌ها را فشرده می‌کند.

در واقع:

-Archive یعنی چند فایل را داخل یک فایل واحد قرار دهیم.

-Compression یعنی حجم داده‌ها را کاهش دهیم.

برای مثال :

فرض کنید یک دایرکتوری دارین که توی یکسری فایل وجود داره
```
photos/
  img1.jpg
  img2.jpg
  img3.jpg
```

# دستورات و نکات لازم

دستور زیر فقط همه فایل‌ها را در یک فایل قرار می‌دهد:

```bash {1}
orbitux@pop-os:~ tar -cf photos.tar photos
```
اما حجم فایل تقریباً تغییری نمی‌کند.

اگر بخواهیم حجم نیز کاهش پیدا کند باید از یک الگوریتم فشرده‌سازی مانند gzip یا xz استفاده کنیم.

## دستور tar

ساخت آرشیو:

```bash
orbitux@pop-os:~ tar -cf archive.tar folder
```
نمایش محتویات:

```bash
orbitux@pop-os:~ tar -tf archive.tar/
```

استخراج فایل:

```bash
orbitux@pop-os:~ tar -xf archive.tar/
```

## فشرده‌سازی با gzip

ساخت فایل:

```bash
orbitux@pop-os:~ tar -czf archive.tar.gz folder/
```
استخراج:

```bash
orbitux@pop-os:~ tar -xzf archive.tar.gz
```

پارامترها:

| گزینه | توضیح |
|-------|-------|
| c | ساخت آرشیو |
| x | استخراج  |
| z | استفاده از gzip |
| f | نام فایل |
| v | نمایش فایل‌های در حال پردازش |

## فشرده‌سازی با bzip2

فشرده‌سازی:

```bash
orbitux@pop-os:~ tar -cjf archive.tar.bz2 folder/
```

استخراج: 

```bash
orbitux@pop-os:~ tar -xjf archive.tar.bz2/
```
مزایا:

- حجم کمتر نسبت به gzip

## فشرده‌سازی با xz

اگر بیشترین میزان فشرده‌سازی را می‌خواهید:

```bash
orbitux@pop-os:~ tar -cJf archive.tar.xz folder/
```
استخراج:

```bash
orbitux@pop-os:~ tar -xJf archive.tar.xz/
```
مزایا:
- حجم بسیار کم

معایب: 
- سرعت فشرده سازی پایینتر

## کار با zip

ساخت فایل zip:

```bash
orbitux@pop-os:~ zip -r archive.zip folder/
```
استخراج:

```bash
orbitux@pop-os:~ unzip archive.zip
```

<Callout type="info">

  فرمت ZIP بیشتر برای انتقال فایل بین ویندوز و لینوکس استفاده می‌شود.

</Callout>

خب حالا یک مقایسه کلی و سریع بکنیم ببینیم کدوم فرمت بهتره 

| فرمت | سرعت | میزان فشرده‌سازی | کاربرد |
|-------|-------|------------------|---------|
| tar   | ⭐⭐⭐⭐⭐ | ندارد            | فقط آرشیو |
| gzip  | ⭐⭐⭐⭐⭐ | ⭐⭐⭐            | استفاده روزمره |
| bzip2 | ⭐⭐⭐   | ⭐⭐⭐⭐          | حجم کمتر |
| xz    | ⭐⭐    | ⭐⭐⭐⭐⭐        | انتشار نرم‌افزار |
| zip   | ⭐⭐⭐⭐ | ⭐⭐⭐            | سازگاری با ویندوز |


## مشاهده محتویات بدون استخراج

```bash
orbitux@pop-os:~ tar -tf archive.tar.gz
```

## استخراج در مسیر دلخواه

```bash
orbitux@pop-os:~ tar -xzf archive.tar.gz -C /home/user/Desktop/
```
## فشرده کردن یک فایل

```bash
orbitux@pop-os:~ gzip file.txt
```

خروجی:

```bash
file.txt.gz
```

بازگرداندن:

```bash
orbitux@pop-os:~ gunzip file.txt.gz
```

## بررسی حجم فایل‌ها

قبل: 

```bash
orbitux@pop-os:~ du -sh folder
```

بعد: 

```bash
orbitux@pop-os:~ du -sh archive.tar.gz
```

## چه زمانی از هر کدام استفاده کنیم؟

- tar: زمانی که فقط می‌خواهید چند فایل را در یک فایل واحد قرار دهید.
- gzip: بهترین انتخاب برای استفاده روزمره؛ سریع و با پشتیبانی گسترده.
- bzip2: زمانی که حجم کمتر از سرعت مهم‌تر است.
- xz: مناسب برای انتشار نرم‌افزارها و فایل‌های بزرگ که بیشترین فشرده‌سازی اهمیت دارد.
- zip: زمانی که فایل قرار است بین لینوکس، ویندوز و macOS جابه‌جا شود.

## جمع‌بندی

اگر فقط یک روش را بخواهید یاد بگیرید، پیشنهاد می‌کنم ابتدا `tar` همراه با `gzip` را یاد بگیرید؛ زیرا رایج‌ترین ترکیب در دنیای لینوکس است و تقریباً در همه توزیع‌ها و پروژه‌های متن‌باز با فایل‌های `.tar.gz` روبه‌رو خواهید شد. پس از آن، آشنایی با `xz` و `zip` می‌تواند نیازهای پیشرفته‌تر و سناریوهای مختلف را پوشش دهد.
